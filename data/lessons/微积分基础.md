## 核心内容
### 1. 极限：微积分的基石
- **定义**：当 $x$ 趋近 $a$ 时，$f(x)$ 的极限 $\lim_{x \to a} f(x) = L$ 表示 $f(x)$ 无限接近 $L$。
- **为什么重要**：导数和积分均基于极限概念。例如，瞬时速度是位移函数的极限。
- **计算技巧**：利用代数简化（如因式分解）避免“0/0”型未定式（您已掌握的多项式运算可直接应用）。

### 2. 导数：变化率的量化
- **几何意义**：函数在某点的切线斜率（关联向量基础中的方向概念）。
- **核心公式**：
  - 导数定义：$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$
  - 基本法则：
    - 幂法则：$\frac{d}{dx}x^n = n x^{n-1}$
    - 链式法则：$\frac{d}{dx}f(g(x)) = f'(g(x)) \cdot g'(x)$
    - 三角函数：$\frac{d}{dx}\sin x = \cos x$, $\frac{d}{dx}\cos x = -\sin x$
- **物理意义**：速度是位移的导数，加速度是速度的导数（结合您熟悉的数据结构中的状态变化模型）。

### 3. 积分：累积效应的度量
- **不定积分**：导数的逆运算，$\int f(x)  dx = F(x) + C$，其中 $F'(x) = f(x)$。
- **定积分**：$\int_a^b f(x)  dx$ 表示曲线下的面积（几何意义）。
- **微积分基本定理**：$\int_a^b f(x)  dx = F(b) - F(a)$，连接导数与积分（核心桥梁）。

### 4. 与编程实践的融合
- 利用Python的`SymPy`库符号化计算导数/积分（衔接您已掌握的函数定义和数据结构）：
  ```python
  import sympy as sp
  x = sp.symbols('x')
  f = x**2 + sp.sin(x)  # 定义函数（结合代数和三角学）
  derivative = sp.diff(f, x)  # 求导：2*x + cos(x)
  integral = sp.integrate(f, x)  # 积分：x**3/3 - cos(x)
  ```

## 实例讲解
### 实例1：导数在优化中的应用（衔接后续优化算法）
- **问题**：求 $f(x) = x^2 - 4x + 3$ 的最小值（类似机器学习中的损失函数最小化）。
- **步骤**：
  1. 求导：$f'(x) = 2x - 4$
  2. 设导数为零：$2x - 4 = 0 \Rightarrow x = 2$
  3. 二阶导数验证：$f''(x) = 2 > 0$，故 $x=2$ 是最小值点。
- **Python验证**：
  ```python
  import numpy as np
  x = np.linspace(-1, 5, 100)
  y = x**2 - 4*x + 3
  min_index = np.argmin(y)  # 找到最小值索引
  print(f"最小值点: x={x[min_index]:.2f}, y={y[min_index]:.2f}")  # 输出: x=2.00, y=-1.00
  ```

### 实例2：积分计算概率（衔接后续概率论）
- **问题**：计算标准正态分布 $f(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}$ 在 $[-1,1]$ 的概率（即 $\int_{-1}^{1} f(x)  dx$）。
- **步骤**：
  1. 利用微积分基本定理：需找到原函数（但 $e^{-x^2/2}$ 无初等原函数）。
  2. 采用数值积分（梯形法）—— 您已掌握的数据结构（数组操作）可直接应用：
     ```python
     def normal_pdf(x):
         return (1 / np.sqrt(2 * np.pi)) * np.exp(-x**2 / 2)
     x_vals = np.linspace(-1, 1, 100)
     y_vals = normal_pdf(x_vals)
     integral = np.trapz(y_vals, x_vals)  # 梯形法积分
     print(f"概率 ≈ {integral:.4f}")  # 输出: ≈0.6827（与68%经验规则一致）
     ```

### 编程任务（强化Python应用）
```python
# 任务1: 实现数值微分（利用您已掌握的函数和循环）
def numerical_derivative(f, x, h=1e-5):
    """使用中心差分法计算导数"""
    return (f(x + h) - f(x - h)) / (2 * h)

# 测试: f(x) = sin(x), 在 x=0 处导数应为 cos(0)=1
print(numerical_derivative(np.sin, 0))  # 验证输出接近1.0

# 任务2: 实现黎曼和计算定积分
def riemann_sum(f, a, b, n=1000):
    """用右端点黎曼和计算 ∫_a^b f(x) dx"""
    dx = (b - a) / n
    x = np.linspace(a + dx, b, n)
    return np.sum(f(x)) * dx

# 测试: ∫_0^π sin(x) dx 应等于 2
print(riemann_sum(np.sin, 0, np.pi))  # 验证输出接近2.0
```

### 挑战题（衔接后续知识点）
- 使用梯度下降法（后续优化算法基础）最小化 $h(x) = x^2 + 2x$：

     ```python
     def gradient_descent(learning_rate=0.1, steps=100):
         x = 10.0  # 初始点
         for _ in range(steps):
             grad = 2*x + 2  # 梯度
             x -= learning_rate * grad
         return x
     print(gradient_descent())  # 应接近 -1.0（最小值点）
     ```

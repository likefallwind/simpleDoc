## 核心内容
### 1. 随机变量：从确定性到随机性的桥梁
- **定义**：随机变量是将随机实验结果映射为实数的函数（例如，抛硬币：正面=1，反面=0）。  
- **离散型 vs 连续型**：  
  - **离散型**：取值有限或可数（如掷骰子的点数）。关键工具：**概率质量函数（PMF）**，表示P(X=x)。  
  - **连续型**：取值连续区间（如身高、温度）。关键工具：**概率密度函数（PDF）**，表示f(x)≥0且∫f(x)dx=1。  
- **为什么重要？** 在强化学习中，随机变量建模环境状态（如机器人位置的不确定性），是决策的基础。

### 2. 期望：决策的“平均收益”核心
**重点聚焦：离散和连续随机变量的期望计算**  
- **期望定义**：随机变量的加权平均值，反映长期实验的中心趋势。  
- **离散型期望计算**：  
  \[
  E[X] = \sum_{x} x \cdot P(X=x)
  \]  
  示例：公平骰子期望 = \(1 \times \frac{1}{6} + 2 \times \frac{1}{6} + \cdots + 6 \times \frac{1}{6} = 3.5\)。  
- **连续型期望计算**：  
  \[
  E[X] = \int_{-\infty}^{\infty} x \cdot f(x)  dx
  \]  
  示例：身高服从正态分布N(170, 10²)，期望 = ∫x·f(x)dx = 170（利用微积分中已知的正态分布性质）。  
- **决策应用**：在优化中，期望值指导最优选择（如强化学习中的策略选择：选择期望回报最大的动作）。

### 3. 概率分布：刻画随机性的工具箱
- **离散分布**：  
  - 二项分布（Binomial）：n次独立试验的成功次数（如10次抛硬币中正面的次数）。  
  - 应用：建模强化学习中的“成功-失败”决策序列。  
- **连续分布**：  
  - 正态分布（Gaussian）：由均值μ和方差σ²定义，PDF为 \( f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} \)。  
  - 应用：传感器噪声建模（如机器人定位中的误差分布）。  
- **决策优化中的角色**：通过分布计算期望效用，选择最大化期望收益的策略（例如，在资源分配中最小化风险）。

### 4. 条件概率：基于新信息的推理
- **定义**：P(A|B) = P(A∩B)/P(B)，表示已知B发生时A的概率。  
- **贝叶斯定理**：P(A|B) = [P(B|A)P(A)] / P(B)，用于更新信念（如观测到数据后调整概率）。  
- **强化学习关联**：在部分可观测环境（如POMDP）中，条件概率用于状态估计（后续“马尔可夫决策过程”的核心）。

## 重点难点
- **重点**：  
  - 期望计算是本知识点的**核心技能**，离散用求和、连续用积分（您已有的微积分知识将大幅提升效率）。  
  - 概率分布在决策中的应用：期望值不仅是数学概念，更是优化目标（例如，在强化学习中，值函数V(s) = E[未来回报|状态s]）。  
- **难点**：  
  - **连续期望的积分技巧**：当PDF复杂时（如指数分布），需熟练应用积分方法（建议结合Python数值积分验证）。  
  - **条件概率的直观理解**：易混淆P(A|B)与P(B|A)（例如，疾病检测中的假阳性问题）。**突破技巧**：始终用具体数字示例验证。  
  - **分布选择陷阱**：误用离散分布处理连续数据（如用二项分布近似身高）。**解决方案**：先分析数据特性（可数 vs 连续）。

## 实例讲解
### 实例1：离散期望在A/B测试中的应用（结合您的算法背景）
**场景**：您开发的推荐系统有两个策略（A和B），用户点击率服从二项分布。策略A：100次展示中点击20次；策略B：100次展示中点击25次。哪个策略期望点击率更高？  
- **计算**：  
  - E[点击率_A] = 20/100 = 0.2  
  - E[点击率_B] = 25/100 = 0.25  
- **决策**：选择B（期望更高）。但需注意：实际中需用置信区间评估可靠性（后续“统计学基础”深化）。  
- **Python验证**（利用您掌握的`numpy`）：  
  ```python
  import numpy as np
  # 模拟1000次A/B测试
  clicks_A = np.random.binomial(n=100, p=0.2, size=1000)
  clicks_B = np.random.binomial(n=100, p=0.25, size=1000)
  print("A的平均点击率:", clicks_A.mean()/100)  # 约0.2
  print("B的平均点击率:", clicks_B.mean()/100)  # 约0.25
  ```

### 实例2：连续期望在机器人路径规划中的应用（结合微积分）
**场景**：机器人移动距离X服从正态分布N(5, 1²)（单位：米）。计算期望距离，并解释其在能耗优化中的意义。  
- **计算**：  
  E[X] = ∫x·(1/√(2π))e^(-(x-5)²/2) dx = 5（利用正态分布期望性质，无需手动积分）。  
- **决策应用**：若能耗与距离成正比，则期望距离5米指导电池分配（选择期望能耗最低的路径）。  
- **Python可视化**（利用`matplotlib`）：  
  ```python
  import matplotlib.pyplot as plt
  x = np.linspace(2, 8, 100)
  pdf = (1/np.sqrt(2*np.pi)) * np.exp(-(x-5)**2 / 2)
  plt.plot(x, pdf)
  plt.axvline(x=5, color='r', linestyle='--', label='E[X]=5')
  plt.title("机器人移动距离的PDF")
  plt.legend()
  plt.show()
  ```

     ```python
     def expected_value(values, probs):
         return sum(x * p for x, p in zip(values, probs))
     # 测试：骰子期望
     print(expected_value([1,2,3,4,5,6], [1/6]*6))  # 应输出3.5
     ```

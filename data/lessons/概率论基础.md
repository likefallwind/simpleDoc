## 核心内容
概率论是强化学习的基石，尤其在处理不确定性（如状态转移和奖励）时至关重要。我们将从基础概念讲起，逐步过渡到强化学习应用场景。

### 1. 基本概念
- **样本空间（Ω）**：所有可能结果的集合。例如，掷骰子的样本空间 Ω = {1, 2, 3, 4, 5, 6}。
- **事件（A）**：样本空间的子集。例如，"掷出偶数"事件 A = {2, 4, 6}。
- **概率公理**（柯尔莫哥洛夫公理）：
  - $0 \leq P(A) \leq 1$
  - $P(\Omega) = 1$
  - 互斥事件并集的概率等于概率之和（$P(A \cup B) = P(A) + P(B)$ 当 $A \cap B = \emptyset$）

### 2. 条件概率与贝叶斯定理
- **条件概率**：$P(A|B) = \frac{P(A \cap B)}{P(B)}$，表示在事件B发生的条件下A发生的概率。
- **贝叶斯定理**：$P(A|B) = \frac{P(B|A) P(A)}{P(B)}$，用于根据新证据更新概率（在强化学习中用于策略调整）。
- **独立性**：若 $P(A|B) = P(A)$，则A与B独立（例如，强化学习中的状态转移常假设马尔可夫性）。

### 3. 随机变量与分布
- **随机变量（X）**：将样本空间映射到实数的函数（如骰子点数）。
- **离散型分布**：结果有限（如伯努利分布：$P(X=1)=p$, $P(X=0)=1-p$），适用于强化学习中的离散动作。
- **连续型分布**：结果无限（如均匀分布：$f(x) = \frac{1}{b-a}$ for $a \leq x \leq b$），需用微积分处理密度函数。
- **关键分布**：
  - 伯努利分布：模拟单次试验（如"动作成功"与否）。
  - 均匀分布：初始状态假设（如强化学习中的探索策略）。

### 4. 期望与方差
- **期望（E[X]）**：长期平均值，离散型 $E[X] = \sum x_i P(X=x_i)$，连续型需积分。
- **方差（Var(X)）**：衡量波动性，$Var(X) = E[(X - E[X])^2]$。
- **强化学习意义**：值函数 $V(s)$ 本质是期望累积奖励（$E[\sum \gamma^t R_{t+1}]$），方差影响策略稳定性。

## 重点难点
- **重点**：
  - 条件概率是理解MDP状态转移的核心（后续知识点）。
  - 贝叶斯定理用于动态更新信念（例如，机器人根据传感器数据调整行动）。
  - 期望值在强化学习中直接定义值函数（链接到下一个知识点）。
- **难点**：
  - **连续分布与微积分**：您可能担心积分计算。**解决方案**：用Python数值计算（如`scipy.integrate`），避免手动推导（示例见下文）。
  - **贝叶斯定理的应用**：易混淆先验/后验概率。**技巧**：始终用具体场景思考（如"医疗检测误判"）。
  - **独立性假设**：强化学习中常假设状态转移独立，但实际可能有依赖——这正是MDP要解决的问题（后续知识点）。

## 实例讲解
### 实例1：用Python模拟抛硬币（离散概率）
强化学习中常用此模拟探索-利用权衡：
```python
import random
from collections import Counter

# 模拟1000次抛硬币（伯努利分布，p=0.5）
trials = [1 if random.random() < 0.5 else 0 for _ in range(1000)]  # 1=正面, 0=反面
counts = Counter(trials)
prob_heads = counts[1] / len(trials)  # 频率近似概率

print(f"正面频率: {prob_heads:.2f} (理论概率: 0.5)")
# 输出示例: 正面频率: 0.51 (理论概率: 0.5)
```
**强化学习关联**：此代码类似ε-greedy策略——随机探索（抛硬币）决定是否尝试新动作。

### 实例2：贝叶斯定理在机器人决策中的应用
假设机器人检测障碍物：
- 先验概率 $P(障碍)=0.2$
- 传感器准确率 $P(检测|障碍)=0.9$，误报率 $P(检测|无障碍)=0.1$
- 计算当传感器检测到障碍时，真实有障碍的概率：
  $$
  P(障碍|检测) = \frac{P(检测|障碍)P(障碍)}{P(检测)} = \frac{0.9 \times 0.2}{(0.9 \times 0.2) + (0.1 \times 0.8)} = \frac{0.18}{0.26} \approx 0.69
  $$
**关键点**：即使传感器报警，真实概率仅69%——这解释了为何强化学习需多次采样更新策略。

## 实践练习
通过动手实践巩固概念（使用您熟悉的Python）：
1. **基础练习**：编写函数计算掷两个骰子时点数和为7的概率（提示：枚举所有36种结果）。
   ```python
   def dice_sum_probability(target=7):
       outcomes = [(i, j) for i in range(1, 7) for j in range(1, 7)]
       success = [pair for pair in outcomes if sum(pair) == target]
       return len(success) / len(outcomes)
   print(dice_sum_probability())  # 应输出 ≈0.1667
   ```

2. **强化学习应用**：模拟一个简单环境，其中状态转移有50%概率成功（伯努利分布）。计算100次试验中成功次数的期望和方差。
   ```python
   import numpy as np
   successes = [1 if random.random() < 0.5 else 0 for _ in range(100)]
   print(f"期望: {np.mean(successes):.2f}, 方差: {np.var(successes):.2f}")
   ```

3. **挑战题**：用贝叶斯定理扩展练习2——假设初始成功概率未知（先验均匀分布），每次试验后更新后验概率。思考这对强化学习策略优化的意义。

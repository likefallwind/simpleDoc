## 核心内容
### 1. 角度与弧度
- **角度制**：以度(°)为单位，圆周为360°（如直角=90°）。
- **弧度制**：以半径长度定义，圆周为2π弧度（如直角=π/2弧度）。  
  **转换公式**：  
  \[
  \text{弧度} = \text{角度} \times \frac{\pi}{180}, \quad \text{角度} = \text{弧度} \times \frac{180}{\pi}
  \]  
  *为什么重要？* 微积分中所有三角函数默认使用弧度制（后续知识点）。

### 2. 三角函数定义（单位圆视角）
在单位圆（半径=1）中，设角度θ从x轴正方向逆时针测量：
- **正弦（sin θ）**：y坐标值 → `sin θ = y`
- **余弦（cos θ）**：x坐标值 → `cos θ = x`
- **正切（tan θ）**：y/x（x≠0） → `tan θ = sin θ / cos θ`  
  **关键性质**：
  - 周期性：`sin(θ + 2π) = sin θ`，`cos(θ + 2π) = cos θ`
  - 奇偶性：`sin(-θ) = -sin θ`（奇函数），`cos(-θ) = cos θ`（偶函数）

### 3. 基本三角恒等式
- **勾股恒等式**：`sin²θ + cos²θ = 1`（源自单位圆方程`x² + y² = 1`）
- **商数关系**：`tan θ = sin θ / cos θ`
- **和角公式**（简化版）：  
  `sin(α + β) = sin α cos β + cos α sin β`  
  `cos(α + β) = cos α cos β - sin α sin β`  
  *应用提示：这些是微积分中求导/积分的基础（如后续微积分知识点）。*

## 实例讲解
### 实例1：角度转换与函数计算（结合Python）
**问题**：将45°转换为弧度，并计算sin(45°)。  
**数学解法**：  
\[
45° \times \frac{\pi}{180} = \frac{\pi}{4} \text{ 弧度}, \quad \sin(45°) = \frac{\sqrt{2}}{2} \approx 0.7071
\]  
**Python验证**（利用您已掌握的`math`库）：
```python
import math

# 角度转弧度
angle_deg = 45
angle_rad = math.radians(angle_deg)  # 输出: 0.7854 (≈π/4)

# 计算sin值
sin_value = math.sin(angle_rad)     # 输出: 0.7071
print(f"sin({angle_deg}°) = {sin_value:.4f}")  # 结果: sin(45°) = 0.7071
```

### 实例2：勾股恒等式应用
**问题**：已知`cos θ = 0.6`，求`sin θ`（θ在第一象限）。  
**解法**：  
\[
\sin^2 θ = 1 - \cos^2 θ = 1 - (0.6)^2 = 0.64 \implies \sin θ = \sqrt{0.64} = 0.8 \quad (\text{第一象限取正值})
\]  
**Python验证**：
```python
cos_theta = 0.6
sin_theta = math.sqrt(1 - cos_theta**2)  # 输出: 0.8
```

### 实例3：和角公式实践（为微积分铺垫）
**问题**：计算`sin(75°) = sin(45° + 30°)`。  
**解法**：  
\[
\sin(75°) = \sin(45°)\cos(30°) + \cos(45°)\sin(30°) = \left(\frac{\sqrt{2}}{2}\right)\left(\frac{\sqrt{3}}{2}\right) + \left(\frac{\sqrt{2}}{2}\right)\left(\frac{1}{2}\right) = \frac{\sqrt{6} + \sqrt{2}}{4} \approx 0.9659
\]  
*关联后续：微积分中求`d/dx [sin(x)]`需用此公式推导极限。*

import math

def verify_pythagorean_identity(theta_deg):
    theta_rad = math.radians(theta_deg)

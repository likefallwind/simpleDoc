## 核心内容
### 1. 向量的本质与表示
- **定义**：向量是既有大小（模长）又有方向的量（如位移、速度），区别于只有大小的标量（如温度）。
- **几何表示**：在坐标系中用带箭头的线段表示（起点到终点），方向由角度决定（关联三角学中的极坐标）。
- **代数表示**：
  - 二维向量：`(x, y)` 或 `[x, y]`（Python列表实现）
  - 三维向量：`(x, y, z)`
  - 模长计算：`||v|| = √(x² + y²)`（直接应用勾股定理）

### 2. 基本向量运算
- **向量加法**：
  - 几何：平行四边形法则或首尾相接
  - 代数：分量相加 `u + v = [u_x + v_x, u_y + v_y]`
  - Python实现：`[a+b for a,b in zip(u, v)]`
- **标量乘法**：
  - 几何：缩放向量长度（正标量保持方向，负标量反向）
  - 代数：`k * v = [k*v_x, k*v_y]`
- **点积（内积）**：
  - 代数：`u · v = u_x*v_x + u_y*v_y`
  - 几何：`u · v = ||u|| ||v|| cosθ`（θ为夹角，关联三角学中的余弦）
  - 意义：衡量向量相似度（机器学习中常用）

### 3. 向量在坐标系中的应用
- **坐标转换**：利用三角学知识，将向量从笛卡尔坐标系转换为极坐标系：
  - `x = r * cosθ`, `y = r * sinθ`（r为模长，θ为角度）
- **单位向量**：模长为1的向量，用于表示方向（`v_norm = [x/||v||, y/||v||]`）

## 重点难点
- **重点**：
  - 向量的方向性：与标量的根本区别（例如：位移 vs 距离）
  - 点积的双重解释：代数计算与几何意义（cosθ关系），这是后续线性代数的核心
  - Python实现效率：避免手动循环，优先使用NumPy向量化操作
- **难点**：
  - **几何直觉建立**：初学者易混淆向量起点（默认原点）与自由向量。**解决方法**：用Matplotlib绘制动态箭头（示例见实例讲解）。
  - **点积的负值理解**：当θ>90°时点积为负，表示方向相反（如物理中的阻力）。**解决方法**：结合三角学中的余弦函数图像分析。
  - **高维扩展**：二维向量易理解，但三维及以上需抽象思维。**解决方法**：从Python列表推广到n维（如机器学习中的特征向量）。

## 实例讲解
### 实例1：用Python实现向量加法（关联您的Python基础）
```python
# 基于您已掌握的列表操作
def vector_add(u, v):
    return [a + b for a, b in zip(u, v)]

# 测试：计算位移向量 (3,4) + (1,2)
displacement1 = [3, 4]
displacement2 = [1, 2]
result = vector_add(displacement1, displacement2)  # 输出 [4, 6]
print(f"总位移: {result}")  # 几何意义：从(0,0)到(4,6)的箭头
```

### 实例2：点积与角度计算（关联三角学基础）
```python
import math

def dot_product(u, v):
    return sum(a * b for a, b in zip(u, v))

def vector_angle(u, v):
    """计算两向量夹角（弧度）"""
    dot = dot_product(u, v)
    mag_u = math.sqrt(sum(x**2 for x in u))
    mag_v = math.sqrt(sum(x**2 for x in v))
    cos_theta = dot / (mag_u * mag_v)
    return math.acos(cos_theta)  # 反余弦函数（三角学应用）

# 测试：向量[1,0]（x轴）与[0,1]（y轴）的夹角
v1 = [1, 0]
v2 = [0, 1]
angle_rad = vector_angle(v1, v2)
print(f"夹角: {math.degrees(angle_rad):.1f}°")  # 输出90.0°，验证垂直关系
```

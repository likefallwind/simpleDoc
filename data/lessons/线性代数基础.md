## 核心内容
本节聚焦线性代数的核心工具，强调计算实践与几何直观。内容设计结合您的Python背景，避免纯理论推导。

### 1. 矩阵与向量的定义与表示
- **矩阵**：$m \times n$ 的矩形数组（$m$ 行 $n$ 列），例如：
  $$
  A = \begin{bmatrix}
  1 & 2 \\
  3 & 4 \\
  5 & 6
  \end{bmatrix}
  $$
  在Python中，用NumPy的`array`表示：
  ```python
  import numpy as np
  A = np.array([[1, 2], [3, 4], [5, 6]])  # 3x2矩阵
  ```
- **向量**：特殊矩阵（$n \times 1$ 列向量），例如 $\mathbf{v} = [2, -1]^T$。  
  **关键关联**：您已掌握的Python列表（如`[2, -1]`）可直接转换为NumPy向量，但NumPy提供高效运算。

### 2. 核心矩阵运算
- **加法与标量乘法**：同维矩阵逐元素操作（类似Python列表推导，但NumPy更高效）。
  ```python
  B = np.array([[0, 1], [2, 3], [4, 5]])
  C = A + B  # [[1,3], [5,7], [9,11]]
  D = 2 * A  # 标量乘法
  ```
- **矩阵乘法**（重点）：$A_{m \times n} \times B_{n \times p} = C_{m \times p}$，其中 $c_{ij} = \sum_{k=1}^n a_{ik}b_{kj}$。  
  **几何意义**：线性变换（如旋转、缩放）。例如，旋转矩阵 $\begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}$ 作用于向量。  
  **Python实现**：
  ```python
  E = np.array([[1, 0], [0, 1]])  # 2x2单位矩阵
  F = np.array([[2], [3]])        # 2x1向量
  result = np.dot(E, F)           # 矩阵乘法，输出 [[2], [3]]
  ```

### 3. 线性方程组与求解
- **矩阵表示**：方程组 $A\mathbf{x} = \mathbf{b}$（如 $\begin{bmatrix} 2 & 1 \\ 1 & -1 \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} 5 \\ 1 \end{bmatrix}$）。
- **高斯消元法**：通过行变换化为行阶梯形。  
  **实践关联**：您已掌握的程序流程控制（如循环）可手动实现，但NumPy提供高效解法：
  ```python
  A = np.array([[2, 1], [1, -1]])
  b = np.array([5, 1])
  x = np.linalg.solve(A, b)  # 输出 [2., 1.]，即 x=2, y=1
  ```

### 4. 行列式与逆矩阵
- **行列式**（$\det(A)$）：标量值，判断矩阵是否可逆（$\det(A) \neq 0$）。  
  **几何意义**：矩阵变换后的面积/体积缩放因子。
- **逆矩阵**（$A^{-1}$）：满足 $A A^{-1} = I$，用于解方程 $A\mathbf{x} = \mathbf{b}$（$\mathbf{x} = A^{-1}\mathbf{b}$）。  
  **Python实现**：
  ```python
  det_A = np.linalg.det(A)  # 计算行列式
  A_inv = np.linalg.inv(A)  # 计算逆矩阵
  ```

## 重点难点
- **重点**：
  - **矩阵乘法的非交换性**：$AB \neq BA$（与标量乘法不同），例如旋转后缩放 vs 缩放后旋转结果不同。
  - **逆矩阵的条件**：仅当 $\det(A) \neq 0$ 时存在，否则方程组无唯一解（联系您已掌握的“异常处理”——在代码中需检查`np.linalg.det(A) != 0`）。
- **难点突破**：
  - **几何直观缺失**：通过Python可视化辅助。例如，用`matplotlib`绘制向量变换前后的图形（代码示例见实例讲解）。
  - **高维理解**：从2D/3D扩展到高维空间（如机器学习中的特征向量），强调“基变换”概念。

## 实例讲解
### 实例：图像旋转（结合Python与几何意义）
假设您有一个2D点集（向量集合），需顺时针旋转90度。  
- **数学原理**：旋转矩阵 $R = \begin{bmatrix} 0 & 1 \\ -1 & 0 \end{bmatrix}$。
- **Python实现**：
  ```python
  import matplotlib.pyplot as plt
  
  # 定义点集（列向量形式）
  points = np.array([[1, 2, 3], [1, 1, 1]])  # 2x3矩阵，每列为一个点
  
  # 旋转矩阵
  R = np.array([[0, 1], [-1, 0]])
  
  # 应用变换
  rotated = R @ points  # @ 表示矩阵乘法
  
  # 可视化
  plt.figure(figsize=(8, 4))
  plt.subplot(1, 2, 1)
  plt.scatter(points[0], points[1], c='red')
  plt.title('Original Points')
  plt.subplot(1, 2, 2)
  plt.scatter(rotated[0], rotated[1], c='blue')
  plt.title('Rotated Points')
  plt.show()
  ```
- **结果分析**：红点(1,1)→(1,-1)，蓝点(2,1)→(1,-2)等，验证旋转效果。  
  **关联应用**：此操作是计算机图形学基础，也是神经网络中数据预处理的常见步骤（如图像增强）。
